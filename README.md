# Atividades Interativas — Processos de Desenvolvimento de Software

Páginas interativas dos **Registros de Aula** da disciplina *Processos de
Desenvolvimento de Software*, no mesmo modelo das atividades de Lógica e de
Redes: cenário, diagrama do conceito, passo a passo guiado, formulário
preenchível e geração do relatório em PDF direto pelo navegador.

**Acesso:** https://olisam2303-ux.github.io/atividades-interativas-processos/

## O que cada página tem

- Aba **Como fazer**: atividade proposta, objetivos, ferramenta e como preencher
- Aba **Diagrama**: o diagrama do conceito da semana
- Aba **Relatório**: identificação do grupo, passos com dica de "como pensar",
  checklist, critérios de avaliação e referências
- Botão **Gerar PDF da resposta**, que monta o relatório no padrão de roteiro de
  aula prática (capa, folha de rosto, objetivos, procedimentos, respostas do
  grupo, checklist e referências) para salvar como `NOME_TURMA_Sxx` e enviar no AVA

Os quizzes *Pause e Responda* continuam na
[apostila interativa de Processos](https://olisam2303-ux.github.io/apostila-processos-interativa/).

## Como usar

Cada arquivo `.html` é autocontido: funciona offline, sem instalar nada. O que o
aluno digita fica salvo apenas no navegador dele (`localStorage`) — nada é
enviado automaticamente.
